Car Price Prediction using Machine Learning

Project Overview

This project predicts the selling price of a used car using machine learning.

Dataset

The project uses a public dataset containing 301 car records.

Technologies Used

- Python
- Pandas
- Scikit-learn
- Random Forest Regressor
- Google Colab

Model Results

- Mean Absolute Error: 0.61 lakh
- R² Score: 0.96
- Sample predicted selling price: 6.13 lakh

How to Run

Open the notebook in Google Colab and run the cells from top to bottom.
